# Backcode runner

Binarios del runner (Releases), install.sh y el plugin de Claude Code de [Backcode](https://backcode.pages.dev). Sin código fuente.

- Instalar: `curl -fsSL https://raw.githubusercontent.com/hernanmateo/backcode-dist/main/install.sh | sh`
- Plugin: `/plugin marketplace add hernanmateo/backcode-dist` y `/plugin install backcode@backcode`
